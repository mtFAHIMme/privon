How it works

Three steps, entirely on your device

No account, no sync, no upload queue — because there is no upload.

01

Pick your files

Choose one file or many through Android's system file picker. Privon never asks for full storage access — SAF hands it only the files you select.

02

Enter a password

Your password is stretched into a 256-bit key through 600,000 PBKDF2 iterations. It is never written to disk, never cached, and never transmitted.

03

Encrypt or decrypt

Each file is sealed with its own random salt and nonce, then written back to the folder you choose. Decryption reverses it exactly.

Under the hood

Standard cryptography, no shortcuts

Privon doesn't roll its own crypto. It uses the same primitives that secure messengers rely on.

Cipher

AES-256-GCM

Authenticated encryption in a single pass. Confidentiality and integrity together — any tampering with the ciphertext is detected and rejected, never silently opened.

Key derivation

PBKDF2 · 600,000 iterations

Your password is stretched into a 256-bit key through 600,000 rounds of PBKDF2, making brute-force guessing by an attacker extremely expensive.

Per-file uniqueness

Fresh salt & nonce, every time

Each file — even in a batch of hundreds — receives its own random 256-bit salt and 96-bit nonce. Encrypting the same file twice never produces the same ciphertext.

Storage access

SAF · zero permissions

Built on Android's Storage Access Framework, so it runs from Android 4.4 up. The manifest declares no internet and no storage permissions at all.

Cross-device compatibility

Old phone, new phone

Android's PBKDF2 only supports SHA-256 from API 26 (Android 8.0) onward, so Privon detects the device and picks the right hash automatically.

On Android 8.0+ Privon uses PBKDF2-HMAC-SHA256. On Android 7.1 and older it falls back to PBKDF2-HMAC-SHA1, because SHA-256 isn't available there. Both paths use the same 600,000 iterations and produce the same 256-bit key — and the hash used is recorded inside the encrypted file, so a newer device always knows how to open a file made on an older one.

✓ WORKS

Old phone → New phone

Encrypt on Android 7 or older, decrypt on Android 8+. The newer device reads the derivation hash from the file and applies it automatically. No settings to change.

✕ NOT SUPPORTED

New phone → Old phone

A file encrypted on Android 8+ uses SHA-256, which older devices cannot compute. Privon reports a clear error instead of failing silently, so you always know why.

About & support

Why Privon exists

A short note on the trade-off that makes the app private, and how you can help keep it free.

Your password is the only key

Because Privon never sends anything anywhere, there is no recovery service, no reset link, and no backup of your password. If you lose it, the files encrypted with it cannot be recovered — by us or anyone else.

That is the trade-off that makes the app private. Store your passwords somewhere safe before you encrypt.

Keep it free

Privon is completely free — no ads, no tracking, no paid tier, no "pro" upgrade waiting behind a paywall. It's built to be useful, not to monetise you.

If it earns a place on your phone, a small donation helps cover the time it takes to keep it updated and improve it over time. Thank you ❤️
